# ShaadiKart brand files

Temporary logo until the final ShaadiKart logo is approved.

To install the final logo:
1. Put the icon-only mark here as `logo-mark.svg` (square, transparent background).
2. Optional: put the full lockup (icon + wordmark) here as `logo-full.svg`, then set `fullLogo: 'img/brand/logo-full.svg'` in `js/data.js` → `BRAND`.
3. Republish. Header, footer, popups, receipts, the browser-tab icon and every other logo spot update automatically.

SVG is preferred. A transparent PNG at least 512 px tall also works (change the file extension in `BRAND`).
